# Contributing to FocusDesk 🤝

First off, thank you for considering contributing to FocusDesk! It’s people like you that make FocusDesk a great tool for everyone.

## How Can I Help?

### 1. Reporting Bugs 🐛
If you find a bug, please open an **Issue** on GitHub. Describe what happened and how to reproduce it.

### 2. Suggesting Features 💡
Have an idea to make FocusDesk better for ADHD brains? Open an **Issue** and label it as a `feature request`.

### 3. Pull Requests 🚀
1. Fork the repo.
2. Create your feature branch (`git checkout -b feature/AmazingFeature`).
3. Commit your changes (`git commit -m 'Add some AmazingFeature'`).
4. Push to the branch (`git push origin feature/AmazingFeature`).
5. Open a Pull Request.

## Coding Style
- Keep it simple.
- Use Vanilla CSS for styling.
- Ensure the UI remains "Neuro-inclusive" (no flashing lights, clear contrast, simple navigation).

## Questions?
Just open an issue and we'll get back to you!
